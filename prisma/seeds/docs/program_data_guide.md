# WISH OS 프로그램 데이터 표준화 가이드 (Programs)

이 문서는 `Program` 모델(방송 프로그램, 라디오, 웹 예능 등)의 데이터 입력 규칙을 정의합니다.
프로그램 정보는 `Event` 스케줄의 기준(Master Data)이 되므로 **정확한 명칭 규칙** 준수가 필수적입니다.

**최종 업데이트:** 2026-01-17

---

## 1. 핵심 원칙: Name vs DisplayName

시스템 내부 로직용 이름(`name`)과 사용자에게 보여주는 이름(`displayName`)을 철저히 분리합니다.

| 필드 | 역할 | 작성 규칙 | 예시 |
| :--- | :--- | :--- | :--- |
| **`name`** | **[Key]** 매칭 및 DB 참조용 | 괄호, 특수문자 금지. **가장 보편적인 한국어 명칭** 사용. | `엠카운트다운`, `뮤직 스테이션` |
| **`displayName`** | **[UI]** 화면 표시용 명칭 | 공식 명칭, 원어, 영어 병기 등을 포함. | `엠카운트다운 (M COUNTDOWN)`, `뮤직 스테이션 (M스테)` |
| **`aliases`** | 검색 및 매칭 보조 | 줄임말, 별칭 등 사용자가 검색할 법한 단어들. | `['엠카', 'MCD']`, `['음중']` |

---

## 2. 국가별 입력 가이드

### 🇰🇷 대한민국 (KR)
* **Name:** 방송사의 공식 한글 명칭을 사용합니다. (줄임말 지양)
* **Network:** 방송사 이름은 **영문 대문자 약칭**을 표준으로 합니다.
    * `KBS 2TV` -> `KBS2`
    * `MBC M`, `MBC every1` -> `MBC M` (대표 채널만 표기 권장)
    * `SBS MTV`, `SBS funE` -> `SBS M` (최신 기준)

### 🇯🇵 일본 (JP)
* **Name (가장 중요):** 일본어 원문(가타카나/한자)이 아닌 **한국어 표기**를 `name`으로 사용합니다.
    * 이유: 개발자가 입력하기 편하고, 검색 및 정렬 시 한글 기준이 관리에 용이함.
* **DisplayName:** `한국어 (원어/영어)` 형식을 따릅니다.
* **Network:** 영문 대문자 약칭을 사용합니다. (`TBS`, `TV Asahi`, `NHK`, `CX`(Fuji), `NTV` 등)

## 3. [중요] 시간 표기 가이드 (30시간제)

일본 방송 특유의 30시간제(24시를 넘겨 25시, 26시로 표기하는 방식) 처리 규칙입니다.

### 3-1. Program (기준 정보)
팬들의 인식(방송 요일)을 존중하여 **방송사 표기 그대로 문자열**로 저장합니다.
* **`dayOfWeek`:** 편성표상 요일 (예: 수요일 심야라면 '수요일')
* **`airTime`:** 30시간제 표기 유지 (예: `'26:00'`, `'24:59'`)

### 3-2. Event (실제 스케줄)
타임라인 정렬 정확성을 위해 **실제 달력 날짜(Real Time)**로 변환하여 저장합니다.
* **`date`:** 실제 날짜 (N+1일)
* **`time`:** 24시간제 변환 (예: `26:00` -> `02:00`)
* **`description`:** 혼동 방지를 위해 괄호 안에 방송사 표기 병기 권장.
    * *예: "수요일 26:00 방송 (목요일 02:00)"*

## 4. 프로그램 종류 (ProgramType) 및 웹 예능

유튜브 채널이라도 **정기적인 포맷이 있는 유명 웹 예능**은 `Program`으로 등록하여 관리합니다.

| 타입 | 설명 | Network 표기 | 예시 |
| :--- | :--- | :--- | :--- |
| **`MUSIC_SHOW`** | 순위제 음악방송, 가요제 | 방송사명 | 엠카운트다운, 뮤직뱅크 |
| **`RADIO`** | 라디오 프로그램 | 방송사명 | 컬투쇼, 아이돌 라디오 |
| **`VARIETY_SHOW`** | TV 예능, 서바이벌 | 방송사명 | 주간 아이돌, 라스타트 |
| **`WEB_CONTENT`** | **유명 웹 예능/콘텐츠** | **`YouTube`** | 잇츠라이브, 스튜디오 춤, 문명특급 |

## 6. Event 연결 및 타이틀 표준화

`Event` 생성 시 `title`은 아래 규칙을 따릅니다. `appearance.programName`은 위 표의 **Name**과 100% 일치해야 합니다.

### 6-1. 기본 규칙
**포맷:** `[방송사] 프로그램명 (상세)`

* **단독 송출:** `[SBS M] 더 쇼`
* **공동 송출:** `[ENA/NTV] NCT Universe : LASTART (Ep.1)` (주관 방송사 병기)
* **웹 예능:** `[Studio CHOOM] BE ORIGINAL 'WISH'` (채널명을 방송사처럼 사용)

### 6-2. 특수 상황 표기
* **코멘트 출연 (라디오):** 멤버가 직접 출연하지 않고 녹음 파일만 송출되는 경우.
    * `[TOKYO FM] ONE MORNING (코멘트)`
* **방송사 불분명/동시송출:** 가장 대표적인 TV 채널 하나를 선정하거나 `[Live]` 등 말머리 활용.

### 6-3. Appearance 연결 주의사항
```typescript
// Good Example
{
  title: "[it's Live] 'WISH' 밴드 라이브",
  appearance: {
    programName: '잇츠라이브', // DB의 Program.name (한글) 사용
    role: '게스트'
  }
}
